eegproc.data.windowing.to_supervised_arrays(frame, *, label_column=None, window_sec=None, window_samples=None, window_rows=1, overlap=0.0, normalize=None, label_transform=None, on_short_trial='error')[source]

Window each trial separately and return channels-last float32 arrays.

kind='features' treats each row as a precomputed feature window. For signals, specify either window_sec or window_samples. Incomplete trailing windows are dropped. Trial identifiers are globally unique across subjects, including when subjects reuse the same trial names.

Optional subject_zscore uses all unlabeled rows from each subject. This includes held-out subjects’ own signals; use normalize=None and fold-specific preprocessing when the evaluation requires training-only normalization statistics.
