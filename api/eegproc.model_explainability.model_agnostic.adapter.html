eegproc.model_explainability.model_agnostic.adapter module

Model and dataset contracts for architecture-agnostic counterfactuals.

Adapters isolate model-specific state initialization, classification, decoding, and optional validity metrics from the optimizer. External projects can provide an adapter factory without changing EEGProc; factories are addressed as package.module:function and receive model_path, config, and one sample trial.
