Bases: BaseEncoder

Band-separated residual GCN encoder for EEG sequence data.

Input shape:

(batch, timesteps, n_channels * n_bands)

The flattened feature axis is interpreted in channel-major order:

[ch0_band0, ch0_band1, …, ch1_band0, ch1_band1, …]

At each timestep, the input is reshaped to:

(batch, timesteps, n_channels, n_bands)

Each frequency band is then processed by its own independent GCN stack:

band_0 -> GCN stack 0 band_1 -> GCN stack 1 … band_k -> GCN stack k

Therefore, every band has its own:

  • GraphConv weights

  • learnable electrode adjacency matrices

  • normalization layers

  • residual projections

Bands never mix inside the graph convolutions. Their node-preserving graph outputs are concatenated only after all per-band GCN stacks have completed.

The output remains:

(batch, ceil(timesteps / t_down), emb_dim)

so it remains compatible with downstream BiLSTM sequence models.

Bases: Model

Graph-aware decoder for GCNEncoder latent sequences.

The decoder first restores temporal resolution. It then projects each latent timestep into a distinct feature vector for every electrode, reshapes that vector back to a graph, and applies residual graph-convolution blocks before reconstructing the frequency-band values at each node.

This is intentionally different from a purely temporal Conv1D decoder: the output is reconstructed as n_channels graph nodes rather than as one undifferentiated flat feature vector.
