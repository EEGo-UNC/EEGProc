# Spectral typicality assessment

We assess each counterfactual EEG trial through its electrode-wise band-power pattern. Within each existing time window, we remove the signal mean, apply a Hann window, and estimate the power spectral density. We average these spectra across windows and integrate power within theta (4–8 Hz), alpha (8–13 Hz), and beta (13–30 Hz), using each band's corresponding filtered signal. The resulting 14-electrode × 3-band representation contains 42 power values. Taking the logarithm of each value produces a compact descriptor of the trial's spectral power distribution.

For each held-out subject and target class, real target-class trials from the source subjects form the reference and calibration sets. A deterministic split assigns approximately two thirds of these source subjects to the reference set and one third to calibration. Reference-set means and standard deviations standardize the 42 log-power features. A trial's typicality score is its root-mean-square feature distance to the fifth-nearest reference trial, with the neighbor count capped at the available reference size. The acceptance threshold is the empirical 95th percentile of calibration-trial scores; a generated trial is accepted when its score is at or below this threshold. We apply the same descriptor, reference set, and threshold to the delivered CFO and CoMTE signals. Each delivered signal is also passed through the same frozen encoder–classifier to evaluate target prediction validity.
